# giro-notes

Small utilities for rounds, receipts and weekly totals.

Nothing clever. Just less paper in my pockets.

## Usage

Requires Python 3. Run from this directory:

```bash
python3 totals.py examples/week.csv
```

The example rows are made up. Amounts are in euros.

Expected total for the example: `200.50 EUR`.
